# Cube

A Rubik's Cube you solve with your keyboard.

- Left hand: **A** left side, **S** top, **D** front. Right hand: **J** right side, **K** bottom, **L** back.
- Each key turns that side clockwise, as if you were looking straight at it. Hold **Shift** to turn it the other way.
- Arrow keys or dragging spin your view. Scramble, then race the timer. On a phone, use the buttons under the cube.

"Solve it for me" uses [cubejs](https://github.com/ldez/cubejs) 1.3.2 (MIT, in `vendor/`, unmodified). It loads only when pressed, and its answer is replayed on the page's own cube model before it plays.
