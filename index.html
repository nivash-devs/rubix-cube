How to read the moves

Each letter is a side of the cube: U top, D bottom, L left, R right, F front, B back. Turn that side as if you were looking straight at it.

A plain letter is a clockwise quarter turn. A letter with ' is a counterclockwise quarter turn. A letter with 2 is a half turn.
